# 凸包與邊界巡遊

平面上有 n 個整數座標點，點的位置可以重複。請先將重複的位置視為同一個點，然後輸出以下四個序列。

**嚴格凸包 H**：依逆時針順序列出凸包頂點，不保留邊上的中間共線點，從字典序最小的點開始，不重複列出起點。

**邊界巡遊 B**：依逆時針順序列出凸包邊界上所有不同的位置，包含邊上的中間共線點，從字典序最小的點開始，不重複列出起點。

**下鏈 L 與上鏈 U**：令 S、T 分別為字典序最小、最大的不同位置。兩條鏈都從 S 走到 T，都只保留嚴格凸包的轉折點，且包含兩端點。下鏈的每一段有向線段都讓所有輸入點位於其左側或線上；上鏈的每一段則讓所有輸入點位於其右側或線上。

字典序比較先看 x，x 相同再看 y。對有向線段 A → B，點 P 的左側、右側分別表示 cross(B − A, P − A) > 0、< 0。

## 退化情況

- 沒有任何點時，四個序列都是空序列。
- 只有一個不同位置時，四個序列都只包含該點。
- 若有 m ≥ 2 個不同位置且全部共線，將它們依字典序記為 P_0, ..., P_(m−1)。此時 H、L、U 均為 `[P_0, P_(m−1)]`；B 是先由 P_0 走到 P_(m−1)，再沿原路返回，省略最後重複的 P_0：

```text
P_0, P_1, ..., P_(m−1), P_(m−2), ..., P_1
```

因此共線情況的 B 可能重複包含中間點，長度為 2m − 2；m = 2 時沒有中間點。

## 輸入格式

第一行為 n，接下來 n 行各為一個點的 x、y。

```text
n
x_0 y_0
...
x_(n−1) y_(n−1)
```

## 輸出格式

依序輸出 H、B、L、U 四個區塊。每個區塊先輸出序列長度，再逐行輸出序列中的座標。不需要輸出區塊名稱或分隔空行。

## 限制

- 0 ≤ n ≤ 200 000。
- 所有座標都是整數，絕對值不超過 10^8。
- 每個輸入檔只有一組資料。
- 時間限制 5 秒，記憶體限制 512 MiB；不設子任務。
