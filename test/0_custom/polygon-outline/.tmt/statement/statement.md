# 輪廓索引與有向面積

有一條由 n 個平面點組成的封閉折線，依序記為 P_0, ..., P_(n−1)，並以最後一個點連回第一個點。點可以重複，折線可以自交；n = 1 或 n = 2 也合法。

我們允許用任意整數作為循環索引。令 norm(i) 是唯一滿足以下條件的整數 j：

```text
0 ≤ j < n，且 i − j 是 n 的倍數。
```

例如 n = 5 時，norm(−1) = 4、norm(−6) = 4、norm(5) = 0。

請處理下列四種操作。

## 讀取頂點

```text
V i
```

輸出目前 P_norm(i) 的 x、y 座標。

## 讀取有向邊

```text
E i
```

輸出目前從 P_norm(i) 指向 P_norm(i+1) 的邊，以「起點 x、起點 y、終點 x、終點 y」四個整數表示。即使兩端點相同，也照常輸出。

## 修改頂點

```text
S i x y
```

將 P_norm(i) 改為 (x,y)。此操作不輸出任何內容。

## 查詢有向面積

```text
A
```

定義目前輪廓的有向面積兩倍為：

```text
D = Σ [x_j × y_((j+1) mod n) − y_j × x_((j+1) mod n)]，0 ≤ j < n。
```

輸出 D 以及它的符號 s：D > 0 時 s = 1，D = 0 時 s = 0，D < 0 時 s = −1。

對不自交的非退化多邊形，D 為正表示頂點依逆時針排列，為負表示順時針排列。對可能自交的輪廓，本題一律使用上述代數定義；不要求求出所有包圍區域的實際面積。n = 1、2 時 D = 0。

## 輸入格式

```text
n q
x_0 y_0
...
x_(n−1) y_(n−1)
operation_1
...
operation_q
```

每個輸入檔只有一組資料。

## 輸出格式

對每個 V、E、A 操作輸出一行，欄位如上。所有輸出都必須是精確整數。

## 限制

- 1 ≤ n ≤ 200 000，1 ≤ q ≤ 200 000。
- 所有座標都是整數，絕對值不超過 10^8；修改後也符合此限制。
- 所有索引 i 都是整數，絕對值不超過 10^9。
- 至少有一個 A 操作。令 A 操作數為 a，保證 n × a ≤ 2 000 000。
- D 可能超過 signed 64-bit 整數的範圍。
- 時間限制 3 秒，記憶體限制 512 MiB，輸出上限 32 MiB；不設子任務。

## 範例

輸入：

```text
4 9
0 0
4 0
4 3
0 3
A
V -1
E 3
S -1 0 4
A
E -5
V 8
S 1 0 0
A
```

輸出：

```text
24 1
0 3
0 3 0 0
28 1
0 4 0 0
0 0
16 1
```

開始時輪廓是一個面積為 12 的長方形。第一次修改將頂點 3 改成 (0,4)；第二次修改使頂點 1 與頂點 0 重合。每次面積查詢仍依同一公式計算。
