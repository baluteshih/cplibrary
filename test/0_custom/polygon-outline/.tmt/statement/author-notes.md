# 輪廓索引與有向面積的出題備註

本文件為作者專用，題面在 [statement.md](statement.md)。目標是 [Geometry/polygon.hpp](../../../../Geometry/polygon.hpp) 的 `at`（const／非 const）、`edge`、`area`、`polygon_dir`。這是 ICPC batch 題，`.test.cpp` 及 CI 串接由使用者親自撰寫，不提供 adapter 或其模板。

## 合約與覆蓋範圍

- n 始終非零，避免在空容器上作循環索引。索引是數學上的非負餘數；負索引、超過一圈的索引，以及正負 n 的倍數都合法。
- 使用者已確認並修正 `at`：const／非 const 版本都應對 signed size 取模，再將負餘數正規化。兩個版本必須一致；`edge` 本身是 const 方法，也應遵守同一規則。
- S 操作可讓使用者透過可修改的索引介面更新點；V/E 是讀取。資料本身不能強迫 driver 採用哪個 overload，因此由使用者自行決定是否在 driver 中核對 const 與非 const 讀取結果，不能宣稱題目單獨證明了兩者都被呼叫。
- 面積輸出是帶符號的兩倍面積，自交與重複點都依公式定義；不能取絕對值，也不能用凸包或實際區域聯集面積取代。方向輸出只是 D 的符號。
- 輸入座標的叉積用 64 位通常足夠，但最多 200 000 項的代數和可能超出 64 位。參考解至少使用 128 位中間值及累加器，並正確輸出十進位。
- 建構子、容器繼承及不同座標型別的轉換不是本題獨立可觀測的輸出；本題主要測試上述幾個公開方法，不將這些語法介面宣稱為完整覆蓋。

## 獨立參考方案

索引在參考解中使用獨立的數學正規化；存放一般點陣列，不使用被測 Polygon。每個 A 從頭計算梯形形式的等價公式 `Σ (x_j − x_next) × (y_j + y_next)`，再取其符號。S、V、E 為 O(1)，整體 O(q + n × a)，空間 O(n)。此方案不是直接複製 header 的程式。

用小型手算、三角形分解及逆序取負交叉檢查面積。規劃少量重複繞行的封閉折線，使 D 超過 signed 64-bit，確認參考解和輸出 checker 都沒有窄化。題面 n × a 的限制讓 library 的 O(n) 面積方法也能正常使用；不要求 O(1) 動態面積維護。

## 測資與錯解

- n = 1、2、3、5、7 等，尤其以非 2 次冪的 n 測負索引與 const 讀取。
- 索引 −1、−n、−n−1、n−1、n、n+1、±10^9；區分直接 `%` 後沒修負號、先轉 unsigned、E 的下一點忘記繞回等錯誤。
- 順／逆時針、面積為零的自交、連續重複頂點、零長邊、全部重合、很薄但非零面積的輪廓。
- S 修改首點／末點後立即查詢 E 和 A，確保沒有快取過期或只更新一條相鄰邊。
- 同一方向重複繞行，使有向面積足夠大；大 q 讀寫搭配受控的 A 次數，既測效能也維持成本。
- 可用錯解：負索引正規化錯、E 永遠輸出 i 與 i+1 原始索引、更新忽略取模、面積取絕對值、忘乘／除 2、32 位乘法、64 位累加、漏掉閉合邊。

## Checker 與預算

預計使用 ICPC 預設精確 token 比對，另確認它不把大整數轉成浮點；不使用數值誤差模式。題面輸出可能超過預設 8 MiB，因此 package 要保留 32 MiB 上限。

規劃約 24 份資料、總原始資料不超過 64 MiB；每份 n × a 都由 validator 精確檢查。基礎序列時間額度 24 × 3 = 72 秒，再乘上驗證解 roster 成本。優先用有辨識力的索引／更新序列，避免大量重複隨機檔案。以上是待確認的預算，不是最低資料筆數。
