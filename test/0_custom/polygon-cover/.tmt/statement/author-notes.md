# 多邊形的多重覆蓋面積：出題備註

作者專用；題面見 [statement.md](statement.md)。目標為 [Geometry/polygon.hpp](../../../../Geometry/polygon.hpp) 的 `polyCoverArea`。回傳長度為 k + 1 的陣列，其中 `area[t]` 是至少被 t 個多邊形覆蓋的面積，`area[0]` 不定義。k = 0 時只有索引 0，題目不輸出數值。這不是恰好覆蓋 t 次的面積，也不需再做後綴和。舊 `polyUnionArea` 保留為第一層面積的相容介面。

## 前置條件與 library 算法

每個多邊形都是正面積、簡單、逆時針；允許連續共線頂點，但不允許重複頂點、零長邊、折返或自交。不同多邊形可完全相同、部分共邊、反向共邊、互相包含、形成洞。

library 沿每條邊掃描與其他多邊形的交點事件；每個正長度區間的 `cnt` 表示其他多邊形覆蓋數，將該段有向面積貢獻計入 `area[cnt + 1]`。同向重合邊必須保留原有按多邊形順序打破平手的處理；反向共邊的有向貢獻會抵銷。相同位置的事件可能產生暫時無效的計數，因此只在區間長度大於零時使用計數作索引。

令總邊數為 M、多邊形數為 k，時間 O(M² log M + k)，額外空間 O(M + k)。所有多邊形非空時 k ≤ M，可寫為 O(M² log M)、O(M)。

## 獨立參考解

沿用垂直分帶法，不引用或複製目標 library：

1. 收集所有頂點及成對線段交點的 x 座標，共線邊不做除法。
2. 每個開放分帶取中點 x；每個簡單多邊形與垂直線的交集由排序後的 y 交點兩兩配對，得到區間。
3. 對全部區間的端點掃描，累計恰好覆蓋 c 次的截面長度，再做後綴和得到至少 t 次的截面長度。
4. 分帶內端點排序不變，各層長度對 x 都是一次函數，因此中點長度乘分帶寬度即為面積。

時間 O(M³ log M)，空間 O(M² + k)。以 long double 計算，並使用精確有理數小例、整數座標壓縮矩形案例與以下恆等式交叉驗證：

- A_1 ≥ A_2 ≥ ... ≥ A_k ≥ 0。
- Σ A_t 等於各多邊形面積總和。
- 恰好覆蓋 t 次的面積為 A_t − A_(t+1)，其中 A_(k+1) = 0。
- 輸入排列、頂點循環位移、整體平移不改變答案。
- k 個完全相同的多邊形：A_1 到 A_k 都等於該圖形面積。重複圖形不可去重。

## 測資與錯解

延續原 32 筆輸入，新增最大 k = 60 的相同三角形，以及兩側各有多層重複多邊形的反向部分共邊案例，共 34 筆。

覆蓋分數面積、凹多邊形、洞、相離、包含鏈、同向與反向共邊、部分重邊、共線頂點、多重交點、近乎平行邊、非常狹窄分帶與總頂點數上限。高層覆蓋不能只靠一般位置隨機資料。

刻意錯解：假設全部相離而只相加、只計兩兩交集、把多邊形當包圍盒、面積取整、輸出恰好覆蓋面積、重複做後綴和、只保留聯集而忽略更高層。

## Checker、預算與 driver

對每個深度獨立檢查 `|a − b| ≤ 10^(-6) × max(1, |b|)`，拒絕非有限數、缺少或多餘 token。k = 0 時只接受沒有數值的輸出。

時限 1 秒、記憶體 512 MiB。資料預算 34 筆、輸入與答案合計不超過 8 MiB；單份程式的筆數 × 時限為 34 秒。完整參考解與錯解的驗證成本另計；不以數百筆隨機資料替代針對性反例。實測與最終結果見 [verification.md](../verification.md)。

使用者自行撰寫 driver 與 CI 串接。目錄內既有 `polygon-union.test.cpp` 僅隨目錄搬移，內容保留原樣；其中舊函式與舊輸出格式需由使用者更新。本次沒有新增或修改 `.test.cpp`，也沒有修改 CI。
