# 多邊形的多重覆蓋面積

平面上有 k 個多邊形區域 P_1, ..., P_k。每個區域都包含多邊形的內部與邊界。對每個整數 t = 1, ..., k，請計算至少被 t 個區域覆蓋的面積 A_t。

各個多邊形都是面積大於零的簡單多邊形，頂點依逆時針順序給定，但不一定是凸多邊形。同一多邊形內的頂點彼此不同；除了相鄰邊的公共端點外，各邊不相交。允許連續三點共線，但不允許邊重疊或折返。

不同多邊形之間可以相離、相交、相切、共享完整或部分邊界、互相包含，甚至完全相同。同一位置若被 c 個多邊形覆蓋，就會計入 A_1, ..., A_c，但不計入更高層。完全相同的多邊形仍分別計算覆蓋次數。各層覆蓋區域可以有多個連通區塊，也可能有洞；覆蓋次數不足的部分不可計入。

若 k = 0，不需輸出任何數值，可以輸出空行。

## 輸入格式

第一行為 k。

接著依序描述每個多邊形：先給一個整數 n_i，再給 n_i 行頂點座標。最後一個頂點會連回第一個頂點，因此不需重複給定起點。

```text
k
n_1
x_1,0 y_1,0
...
x_1,(n_1−1) y_1,(n_1−1)
...
n_k
x_k,0 y_k,0
...
x_k,(n_k−1) y_k,(n_k−1)
```

每個輸入檔只有一組資料。

## 輸出格式

依序輸出 k 個有限實數 A_1, ..., A_k，以空白或換行分隔。每個數值分別檢查：若你的答案為 a，正確答案為 b，必須滿足：

```text
|a − b| ≤ 10^(-6) × max(1, |b|)
```

不可輸出 NaN 或無窮大。

## 限制

- 0 ≤ k ≤ 60。
- 每個多邊形有 3 ≤ n_i 個頂點。
- 所有多邊形的頂點總數不超過 200。
- 所有座標皆為整數，絕對值不超過 10 000。
- 時間限制 1 秒，記憶體限制 512 MiB；不設子任務。

## 範例一

輸入：

```text
3
4
0 0
4 0
4 4
0 4
4
2 0
6 0
6 4
2 4
4
1 1
2 1
2 2
1 2
```

輸出：

```text
24.000000000000 9.000000000000 0.000000000000
```

前兩個正方形的聯集面積為 24，交集面積為 8。第三個正方形的面積為 1，位於第一個正方形內，與第二個正方形只有邊界接觸。因此 A_1 = 24、A_2 = 9、A_3 = 0。

## 範例二

輸入：

```text
2
3
0 0
4 0
0 4
3
0 0
4 0
4 4
```

輸出：

```text
12.000000000000 4.000000000000
```

兩個三角形的面積各為 8，交集面積為 4，所以 A_1 = 12、A_2 = 4。
