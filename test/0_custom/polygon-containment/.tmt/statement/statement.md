# 點在輪廓的哪裡

給定一個平面區域 C 與 q 個查詢點，請判斷每個查詢點是否在 C 的內部、邊界上或外部。

C 由 n 個依序給定的點 P_0, ..., P_(n−1) 定義：

- n = 0：C 為空集合。
- n = 1：C 是 P_0 這個單點。
- n = 2：兩點不同，C 是連接它們的閉線段。
- n ≥ 3：依序連接相鄰點並由最後一點連回起點，得到一個面積大於零的簡單多邊形。C 包含其內部和邊界。頂點可依順時針或逆時針給定，且多邊形不一定凸。

對 n ≥ 3 的情形，頂點彼此不同；除了相鄰邊的共同端點之外，各邊不相交。允許連續三個頂點共線，但不允許邊重疊或沿同一路徑折返。

## 輸入格式

```text
n q
x_0 y_0
...
x_(n−1) y_(n−1)
u_1 v_1
...
u_q v_q
```

n = 0 時沒有頂點座標行。每個輸入檔只有一組資料。

## 輸出格式

對每個查詢點輸出一行：

- `IN`：嚴格位於多邊形內部。
- `ON`：位於邊界上。
- `OUT`：在 C 之外。

單點與線段的內部在本題中一律視為空；在該單點／線段上的點輸出 `ON`。空集合的所有查詢都輸出 `OUT`。

## 限制

- 0 ≤ n ≤ 10 000，1 ≤ q ≤ 200 000。
- max(1,n) × q ≤ 2 000 000。
- 所有座標都是整數，絕對值不超過 10^8。
- 查詢點可以重複，也可以與頂點重合。
- 時間限制 3 秒，記憶體限制 512 MiB；不設子任務。

## 範例

輸入：

```text
6 8
0 0
6 0
6 2
2 2
2 6
0 6
0 0
2 0
3 3
2 3
0 7
0 3
3 6
1 1
```

輸出：

```text
ON
ON
OUT
ON
OUT
ON
OUT
IN
```

這是一個 L 形多邊形。(3,3) 雖位於所有頂點的凸包內，仍不在原多邊形中；(2,3) 位於凹槽旁的直邊上，而 (1,1) 嚴格位於內部。

## 範例二

輸入：

```text
2 4
-2 -2
2 2
0 0
3 3
-2 -2
0 1
```

輸出：

```text
ON
OUT
ON
OUT
```
