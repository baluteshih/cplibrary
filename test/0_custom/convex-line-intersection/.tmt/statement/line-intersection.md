# 有向直線穿過凸多邊形

給定一個嚴格凸多邊形 C，其 n 個不同頂點 C_0, ..., C_(n−1) 依逆時針順序排列。任意三個相鄰頂點不共線，第一個頂點不一定是字典序最小的點。多邊形包含其內部與邊界。

邊 e_i 定義為 C_i 到 C_((i+1) mod n) 的線段，邊和頂點皆使用 0-based 編號。

每筆查詢給定兩個不同的點 A、B，表示一條**無限延伸的有向直線**：

```text
X(t) = A + t × (B − A)，t 為任意實數
```

請按照下列規則輸出該直線與多邊形的交集資訊。

## 交集分類

- `EMPTY`：交集為空。
- `POINT v`：交集只有一個頂點 C_v，也就是直線僅碰到該頂點。
- `EDGE e`：直線與多邊形的一條邊 e 完全共線，交集就是整條邊。此輸出不因直線方向反轉而改變。
- `CUT e f`：直線穿過多邊形內部，交集為正長度的線段。沿 t 增加的方向，先遇到的交集端點所屬邊編號為 e，後遇到的為 f。

對 `CUT`，若某個交集端點恰好是頂點 C_v，**一律將它歸給邊 e_v，即 C_v → C_((v+1) mod n)**，與直線方向無關。這個約定消除頂點同時屬於兩條邊的歧義。

`EDGE` 不是 `CUT`。依嚴格凸多邊形的條件，每筆查詢恰有一種適用分類。交換 A、B 時，`CUT e f` 必須變成 `CUT f e`；其餘三種輸出不變。

## 輸入格式

第一行為 n、q，接下來 n 行為多邊形頂點座標，再接下來 q 行各給定 A_x、A_y、B_x、B_y。

```text
n q
x_0 y_0
...
x_(n−1) y_(n−1)
A_1x A_1y B_1x B_1y
...
A_qx A_qy B_qx B_qy
```

## 輸出格式

每筆查詢輸出一行，格式為上述四種之一。不需要計算或輸出交點座標。

## 限制

- 3 ≤ n ≤ 200 000，1 ≤ q ≤ 200 000。
- 所有座標皆為整數，絕對值不超過 10^8。
- 每筆查詢的 A、B 不同。A、B 本身可在多邊形內、外或邊界上。
- 每個輸入檔只有一組資料；查詢不改變多邊形。
- 時間限制 5 秒，記憶體限制 512 MiB；不設子任務。

## 範例

輸入：

```text
4 7
0 0
4 0
4 4
0 4
0 2 1 2
1 2 0 2
0 0 -1 1
0 0 1 0
0 0 1 1
0 5 1 5
0 4 1 3
```

輸出：

```text
CUT 3 1
CUT 1 3
POINT 0
EDGE 0
CUT 0 2
EMPTY
CUT 3 1
```

前兩條直線只有方向不同，兩個邊編號因此交換。第五條直線穿過頂點 0、2，依約定分別歸給邊 0、2。第七條直線先通過頂點 3，再通過頂點 1，因此輸出 `CUT 3 1`。
