# 有向直線穿過凸多邊形的出題備註

本文件供建立 package 與測試 driver 的 agent 使用，不屬於選手題面。正式敘述在 [line-intersection.md](line-intersection.md)；本題是獨立 batch 題，不需要互動或 grader。

## 驗證目標與前置條件

目標 header 是 [Geometry/convex.hpp](../../../Geometry/convex.hpp)，主要驗證 `lineIntersectConvex`，亦間接涵蓋 `tangentDirection`。

n ≥ 3，不接受單點或線段凸包。每條查詢直線由兩個不同點定義。輸入的非退化凸包必須逆時針、沒有重複頂點及連續共線頂點。Validator 也應排除自交與多重繞行，不能只檢查每個局部轉向；可獨立重建凸包後核對循環序列。

分類與索引答案均唯一，使用精確比對；交點不必輸出浮點座標。

所有輸入座標的絕對值不超過 10^8。差向量與乘法應使用足夠寬的型別，不能先以 32 位整數計算再轉成 64 位。使用獨立參考實作，不以被測 header 當唯一 oracle。

## 實作與測資細節

此題直接表達 `lineIntersectConvex` 的語意，沒有引入交點座標的計算誤差。

```text
(-1, -1)  → EMPTY
(v, -1)   → POINT v
(e, e)    → EDGE e
(e, f)    → CUT e f   （兩個索引不同且均非負）
```

對 CUT，頂點交點歸到該頂點的出邊，而不是按照行進方向挑入邊。依 t 增加決定先後，因此反轉直線方向必須交換 CUT 的兩個索引。EDGE 與 POINT 不交換。

覆蓋：完全相離、平行但不共線、沿邊、僅碰一個頂點、切過兩條邊內部、切過一個頂點及另一條邊、穿過兩個頂點、交集跨越邊編號 n−1／0，以及同一條直線的反向查詢。也要有 A、B 都在多邊形內的例子，確認處理的是無限直線，不是線段 AB。

小規模 oracle 可用精確有理數計算各邊與直線的交集，去除頂點重複交點後依 t 排序，獨立套用四種分類與出邊規則。大規模 reference 須避免每筆掃所有邊。

## 測資成本與交付

先以約 20–40 份有辨識力的資料規劃，不將隨機測資膨脹到數百份。40 份、每份 5 秒的基礎單次序列時間額度為 200 秒，另需考慮驗證解與唬爛解數量。量測實際資料大小及參考解速度後再校準資源限制。

保留退化情況、邊界規則的反例、小型可暴力核對資料及少量上界資料。離線可大量測試變形，但正式資料只保留可區分錯解的代表。

交付本題的 statement、validator、reference、必要 checker、測資與錯解證據。若目標函式無法編譯或違反題面語意，保留最小反例並回報，不應偷偷放寬題目讓它通過。

可做凸包循環位移、整體平移和查詢直線方向反轉。反射時須恢復逆時針順序及重算邊編號；反轉方向只交換 CUT 的兩個索引。
