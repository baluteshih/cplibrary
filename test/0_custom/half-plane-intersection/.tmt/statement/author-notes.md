# 半平面交集的邊界：出題備註

作者專用；題面見 [statement.md](statement.md)。目標是 [Geometry/half_plane_intersection.hpp](../../../../Geometry/half_plane_intersection.hpp) 的 `half_plane_intersection`，也間接測到預設 strict 判斷、平行去冗餘與雙端佇列的首尾收縮。

## 合約與覆蓋範圍

每條非零有向直線代表左側閉半平面。前四條是包含原點的逆時針正方形，所有其他半平面亦嚴格包含原點，因此交集始終有界、有嚴格內點且至少三條真正的邊。這是本題選定的有效域，不宣稱 header 已支援任意空集或退化輸入。

回傳結果應是每條正長度邊的一條輸入直線，依逆時針循環順序排列；起點不固定。相同方向但不同位置的平行線只能保留真正構成邊界的最緊約束。相同支撐線可選任一輸入代表。只在頂點接觸的冗餘線要剔除；不以任意排序的邊集合冒充有序邊界。

輸出整數編號而非僅面積，能觀察回傳的所有直線與順序。使用者的 driver 須自行將回傳的幾何直線對應至合法輸入編號；本文件不提供對應程式碼。

不涵蓋：空輸入、空交集、無界交集、交集為點／線段、零方向直線、浮點 eps。header 尚未描述這些情況的統一回傳規格，不能擅自要求某個 sentinel 或行為；若之後想涵蓋，先確認 API，再另外設計題目。

## 獨立參考解：極對偶凸包

與目標的原平面排序＋佇列半平面交算法不同，使用原點為嚴格內點的極對偶：

1. 將每個約束寫成 a x + b y ≤ c，其中 a = B_y − A_y、b = A_x − B_x、c = a A_x + b A_y。由輸入保證 c > 0。
2. 映成有理數點 (a/c,b/c)。同一個半平面對應同一個對偶點；較鬆的約束不會成為對偶凸包的必要頂點。
3. 使用精確有理數比較與單調鏈求嚴格凸包，去掉重複點及共線非端點。凸包頂點的原始約束恰好對應 primal 交集的正長度邊；對偶凸包逆時針順序對應 primal 逆時針邊界順序。
4. 保留每個凸包點的一個輸入編號即可；不必計算 primal 的浮點交點。

時間 O(n log n)，空間 O(n)。以正分母整數三元組 (a,b,c) 保留點，字典排序用交叉相乘，轉向以三個齊次座標的行列式判斷。座標絕對值上限 C = 10^9 時，|a|, |b| ≤ 2C，|c| ≤ 2C²。齊次行列式六個單項的絕對值總和至多 48C⁴ = 4.8×10^37，仍小於 signed __int128 上限約 1.7×10^38。a、b、c 可存 long long，但所有乘法須在運算前加寬；不能先將 a/c、b/c 轉 double。原模板的叉積可用 8C² 作保守上界，交叉乘積至多 64C⁴ = 6.4×10^37，同樣可由 __int128 容納。

小例 oracle 採 Python Fraction 從輸入正方形逐條裁切，去掉零長邊與共線中間頂點，再對應每條支撐線的輸入等價類。此法約 O(n²)，只核對小量案例，不拿來產最大資料答案。另驗證輸入排列（保持前四條固定）、同向改選整數端點、重複／冗餘約束不變性。

兩組範例均已手工核對邊界頂點；尚未執行 library 或建立 package。

## Checker

Custom checker，不用浮點誤差。

將每條直線正規化為整數 (a,b,c)，以 gcd(|a|,|b|,c) 約分；因 c > 0，不會混淆半平面的方向。官方答案與選手答案都先轉成支撐線等價類。

驗證 m、索引界限、token 數、每條幾何邊恰好一次，以及選手序列與官方序列在某個循環位移後完全相同。允許相同支撐線任意代表與任意起點，不允許反向。可用選手首項定位官方起點，O(n log n + m) 時間，不要枚舉 m 個起點逐一比較。

Validator 檢查 n、B、座標、前四條固定邊、非零方向、每條直線嚴格包含原點及 EOF；不應拒絕平行、重合、只接觸頂點或端點在正方形外的合法限制。

## 測資與錯解

- 只有四邊、交集為三角形、許多邊，以及絕大多數約束冗餘。
- 相同方向的平行線，較緊者分別先出現／後出現；同一支撐線用不同端點長度重複表示。
- 不同方向但共頂點的約束，刪除只接觸頂點的零長邊；同一頂點可由很多限制相交。
- 極角跨越起點、水平／垂直方向、相反平行邊、雙端佇列兩端皆需連續移除的案例。
- 有理數頂點、大座標、近乎平行、64 位中間乘積溢位、浮點對偶點誤合併。
- 最大 n 的少量壓力資料，其中需要有大量真實有效邊，不能全部是容易提早剔除的重複線。
- 錯解：右側半平面、同向保留最鬆約束、按原輸入順序去重、保留共點零長邊、漏做最終首尾收縮、只做佇列一端、int64 中間乘積／double 排序誤判、O(n²) 逐次裁切。
- 另直接測 checker：合法循環位移、合法重合代表必須接受；反序、重複邊、漏邊、額外頂點切線必須拒絕。
