# 圓形覆蓋測試題的出題備註

這份備註提供給建立 package 的 agent，不屬於選手題面。正式敘述在 [statement.md](statement.md)。本題是一般 batch 題，不需要 grader 或互動協定。

## 驗證目標

目標元件為 [Geometry/circle_cover.hpp](../../../Geometry/circle_cover.hpp)。它回傳長度 n + 1 的陣列，第 k 項是「至少覆蓋 k 次」的面積，第 0 項未定義；本題要求輸出第 1 到 n 項，不能只驗證聯集面積。

既有 [TIOJ 1503 測試](../../../test/6_TIOJ/1503.test.cpp) 只取第 1 項、所有圓半徑相同，且目前標記 `IGNORE`。新題應涵蓋不同半徑、重複圓和高覆蓋層數。

## 測資重點

至少保留能區分以下錯誤的代表案例；同一份資料可同時涵蓋多項，不必每一項建立一大組隨機檔案。

- n = 1，以及 n = 500 的效能案例。
- 全部相離、全部相同、同心且半徑不同、嚴格包含鏈，以及包含鏈內有不同重數的重複圓。
- 外切與內切；切點本身不產生額外面積。包含多個圓同切點／交點的情形。
- 一般兩點相交，交疊弧跨越角度排序的切割位置，以及同角度的多個事件。
- 聯集相同但覆蓋重數不同的組合，攔截將重複圓去重或只輸出聯集的解法。
- 存在很多低層覆蓋、但最高幾層為 0 的配置，以及高層仍有正面積的密集配置。
- 整數限制內接近內切／外切的案例、負座標、遠離原點的小圓，檢查數值抵消；不要以不合法的小數座標製造額外精度要求。

可使用明確的退化構造，例如三個半徑為 5、圓心分別為 (5, 0)、(0, 5)、(−5, 0) 的圓，讓多個圓邊界通過原點。若要專測「同角事件」，也應檢查相交點相對被掃描圓心的方向，不能只因為圖看起來對稱就宣稱已覆蓋。

建議先規劃約 30–50 份正式輸入，再依實際反例刪減或替換，而不是增加到數百份。50 份、每份 5 秒的基礎單次序列時間額度為 250 秒；這是規劃值，不是實測耗時。資料檔大小也應量測。5 秒的題面限制是初始設定，最終依預期環境校準。

## 答案與 checker

- 每個 A_k 使用題面指定的逐項混合絕對／相對誤差；特別是正確答案為 0 時，容許的絕對誤差只有 10^(-6)。拒絕缺少答案、額外非空白 token、NaN 及無窮大。
- 不要用被測的 `circle_cover.hpp` 當成唯一答案來源，再拿同一份實作產生 expected output。應有獨立的參考實作及小規模交叉驗證；疑似反例先用解析特例或較高精度確認。
- 不宜單靠 Monte Carlo 或低解析度網格生成答案，無法保證本題的誤差要求。
- 必須能抓到「恰好 k 次」與「至少 k 次」混淆。若另一份獨立演算法回傳恰好覆蓋 k 次的面積 E_k，應先轉成 A_k = E_k + E_(k+1) + ... + E_n。
- 範例答案已用解析公式核對；它們不是對一般測資的正確性保證。

## 可交叉檢查的性質

對合法的答案應有：

```text
A_1 ≥ A_2 ≥ ... ≥ A_n ≥ 0
A_1 + A_2 + ... + A_n = π × (r_1² + r_2² + ... + r_n²)
```

第二個等式計算覆蓋重數的積分，右邊是所有圓面積的總和。兩個性質都只是必要條件，不能代替獨立答案。

此外可對同一配置進行輸入重排、合法範圍內的整體平移、反射或交換 x/y，答案應保持不變；若將圓心與半徑同時乘上整數 s，且仍滿足限制，所有答案應變成原本的 s² 倍。這些變形可在離線測試中大量使用，正式測資只保留有辨識價值的代表。
