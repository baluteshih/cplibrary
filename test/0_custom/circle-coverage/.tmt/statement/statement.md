# 重疊的圓形區域

平面上有 n 個圓形區域。第 i 個區域的圓心為 (x_i, y_i)，半徑為 r_i，包含圓的內部與邊界。

對每個整數 k，1 ≤ k ≤ n，請計算平面上**至少被 k 個圓形區域覆蓋**的部分，其總面積 A_k。

不同編號的區域可能完全相同。即使兩個區域的圓心與半徑都相同，它們仍分別計算一次覆蓋。例如，若有三個完全相同的單位圓，則 A_1、A_2、A_3 都等於 π。

圓形區域之間可能相離、相交、相切，或其中一個包含另一個。題目不保證一般位置：多個圓的邊界可能通過同一點，圓心也可能重合。

## 輸入格式

第一行包含一個整數 n。

接下來 n 行，每行包含三個整數 x_i、y_i、r_i，表示第 i 個圓形區域。

```text
n
x_1 y_1 r_1
x_2 y_2 r_2
...
x_n y_n r_n
```

每個輸入檔只有一組測試資料。

## 輸出格式

輸出 n 行。第 k 行輸出一個實數 A_k，表示至少被 k 個區域覆蓋的總面積。

若你的輸出為 a，正確答案為 b，則必須滿足：

```text
|a - b| ≤ 10^(-6) × max(1, |b|)
```

每個答案分別檢查誤差。若某個覆蓋層數不存在具有正面積的區域，其答案為 0。輸出須為有限實數；不可輸出 NaN 或無窮大。

## 限制

- 1 ≤ n ≤ 500。
- −10 000 ≤ x_i, y_i ≤ 10 000。
- 1 ≤ r_i ≤ 10 000。
- 所有輸入值皆為整數。
- 不要求任何兩個圓形區域不同。

## 範例一

輸入：

```text
4
0 0 2
0 0 1
0 0 1
5 0 1
```

輸出：

```text
15.707963267949
3.141592653590
3.141592653590
0.000000000000
```

圓心在原點、半徑為 2 的區域包含兩個完全相同的單位圓。圓心為 (5, 0) 的單位圓則與它們相離。

至少被一個區域覆蓋的面積為 5π；至少被兩個及至少被三個區域覆蓋的面積均為 π；沒有任何點被四個區域同時覆蓋。

## 範例二

輸入：

```text
2
0 0 1
1 0 1
```

輸出：

```text
5.054815608571
1.228369698609
```

兩個單位圓的圓心距離為 1。至少被兩個區域覆蓋的部分就是兩圓的交集，其面積為 2π/3 − √3/2。至少被一個區域覆蓋的部分為兩圓的聯集。
