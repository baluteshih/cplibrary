# 凸包上的定位與支撐線

給定一個非空凸包 C，以及 q 筆獨立查詢。凸包頂點編號為 0 到 n − 1。

若 n ≥ 3，頂點依逆時針順序給定，且任意三個相鄰頂點不共線；第一個頂點不一定是字典序最小的點。若 n = 2，兩個不同端點依字典序給定；若 n = 1，凸包就是該單點。凸包包含其內部與邊界。

令二維向量的外積為：

```text
cross((a_x,a_y), (b_x,b_y)) = a_x × b_y − a_y × b_x
```

請支援以下三種查詢。

## 點的位置

```text
I x y
```

令 P = (x,y)。輸出：

- `IN`：P 嚴格位於凸包內部。
- `ON`：P 位於凸包邊界。
- `OUT`：P 在凸包之外。

單點與線段的內部面積皆為零：在該單點／線段上的點輸出 `ON`，其餘輸出 `OUT`。

## 方向極值

```text
D dx dy
```

給定非零向量 d = (dx,dy)，輸出一個頂點編號 i，使 cross(d,C_i) 在所有頂點中最大。如果有多個頂點達到最大值，輸出任意一個即可。

## 外點的兩條切線

```text
T x y
```

此種查詢保證 n ≥ 3，且 P = (x,y) 嚴格位於凸包之外。

輸出兩個頂點編號 a、b，**順序固定，不得交換**：

1. 第一條是有向直線 P → C_a，凸包全部位於其左側或線上。
2. 第二條是有向直線 P → C_b，凸包全部位於其右側或線上。

精確地說，對每一個凸包頂點 C_j，都必須滿足：

```text
cross(C_a − P, C_j − P) ≥ 0
cross(C_b − P, C_j − P) ≤ 0
```

這固定了從 P 觀察凸包時，兩條切線的順逆時針關係，定義不依賴極角的起點。如果一條切線包含凸包的一整條邊，可任選該邊的一個端點作為該條切線的接觸頂點，但仍必須維持上述兩條切線的順序。

## 輸入格式

```text
n q
x_0 y_0
...
x_(n−1) y_(n−1)
query_1
...
query_q
```

## 輸出格式

每筆查詢輸出一行。`I` 輸出一個字串，`D` 輸出一個整數，`T` 輸出依上述固定順序排列的兩個整數。

## 限制

- 1 ≤ n ≤ 200 000，1 ≤ q ≤ 200 000。
- 所有頂點、查詢點及方向向量的分量都是整數，絕對值不超過 10^8。
- `D` 的方向不是零向量；`T` 的前置條件如上。
- 頂點不同，輸入滿足上述凸包條件。各筆查詢互不影響凸包。
- 每個輸入檔只有一組資料。
- 時間限制 5 秒，記憶體限制 512 MiB；不設子任務。

## 範例

輸入：

```text
4 8
0 0
4 0
4 4
0 4
I 2 2
I 4 2
I 5 2
D 1 0
D 0 1
T 6 2
T -2 0
I 0 0
```

一組合法輸出：

```text
IN
ON
OUT
2
0
2 1
0 3
ON
```

`D 1 0` 可以輸出 2 或 3，因為兩點的 y 座標同為最大值。`T -2 0` 的第一條切線包含底邊，因此第一個編號可為 0 或 1；第二個編號必須為 3。兩條切線的順序不能顛倒。
