# 兩組位移的合成範圍

給定兩組非空的平面點集 A 和 B。令 P、Q 分別為這兩組點的凸包，並包含凸包的內部與邊界。

考慮所有可以表示成 p + q 的平面點，其中 p ∈ P、q ∈ Q，向量相加按座標逐項進行。這些點形成的集合稱為 P 與 Q 的 Minkowski 和：

```text
P + Q = { (p_x + q_x, p_y + q_y) : p ∈ P, q ∈ Q }
```

請輸出這個集合的嚴格凸包。等價地，你需要求出所有 n × m 個點 A_i + B_j 的凸包，但不一定要逐一列出這些點。

## 輸入格式

第一行為 n、m。接下來 n 行為 A 的點座標，再接下來 m 行為 B 的點座標。各組內可以有重複點、內部點或共線點，輸入不保證有序。

```text
n m
a_0x a_0y
...
a_(n−1)x a_(n−1)y
b_0x b_0y
...
b_(m−1)x b_(m−1)y
```

## 輸出格式

先輸出答案凸包的頂點數 h，再輸出 h 行整數座標。

- 非退化凸多邊形：按逆時針順序，從字典序最小的點開始，不重複起點、不保留邊上的中間共線點。
- 答案是線段：只輸出兩個端點，依字典序由小到大。
- 答案是單點：只輸出該點。

字典序先比較 x，再比較 y。答案的座標仍為整數。

## 限制

- n ≥ 1、m ≥ 1、n + m ≤ 200 000。
- 所有輸入座標都是整數，絕對值不超過 10^8；輸出座標的絕對值可能達到 2 × 10^8。
- 每個輸入檔只有一組資料。
- 時間限制 5 秒，記憶體限制 512 MiB；不設子任務。

## 範例

輸入：

```text
3 2
0 0
2 0
0 2
0 0
1 0
```

輸出：

```text
4
0 0
3 0
1 2
0 2
```

A 的凸包是一個三角形，B 的凸包是一條水平線段。合成範圍的嚴格凸包為上述四邊形。
