# 兩組位移的合成範圍的出題備註

本文件供建立 package 與測試 driver 的 agent 使用，不屬於選手題面。正式敘述在 [minkowski.md](minkowski.md)；本題是獨立 batch 題，不需要互動或 grader。

## 驗證目標與前置條件

目標 header 是 [Geometry/convex.hpp](../../../Geometry/convex.hpp)，主要驗證 `convexMinkowski`。

兩組輸入都非空，不測試函式未承諾的空集合。輸出座標的絕對值可能達到 2 × 10^8，不能套用原始輸入的座標界。答案須精確比對規範化頂點序列。

所有輸入座標的絕對值不超過 10^8。差向量與乘法應使用足夠寬的型別，不能先以 32 位整數計算再轉成 64 位。使用獨立參考實作，不以被測 header 當唯一 oracle。

## 實作與測資細節

點雲可以包含內部點與重複點，Minkowski 函式會先建凸包；測資不能只有已排好序的嚴格凸包。輸出要求規範化：逆時針、字典序最小點為起點、移除中間共線點。Driver 如需調整起點，只旋轉循環序列；若另外重建凸包或刪除冗餘點，應明確記錄，避免掩蓋回傳序列本身的問題。

必要案例包含兩個單點、單點平移一般凸包、平行線段、不平行線段、線段加多邊形，以及兩個多邊形有大量平行邊。交換 A、B 應得到相同規範化答案。不要只驗證頂點集合卻接受自交順序。

以小 n、m 列出全部 n × m 個點對和，再用獨立凸包當 oracle；大測資則須阻擋直接列舉所有點對的解法。此題不要求程式對空輸入作定義。

## 測資成本與交付

先以約 20–40 份有辨識力的資料規劃，不將隨機測資膨脹到數百份。40 份、每份 5 秒的基礎單次序列時間額度為 200 秒，另需考慮驗證解與唬爛解數量。量測實際資料大小及參考解速度後再校準資源限制。

保留退化情況、邊界規則的反例、小型可暴力核對資料及少量上界資料。離線可大量測試變形，但正式資料只保留可區分錯解的代表。

交付本題的 statement、validator、reference、必要 checker、測資與錯解證據。若目標函式無法編譯或違反題面語意，保留最小反例並回報，不應偷偷放寬題目讓它通過。

可重排各組點雲、交換 A／B、平移或反射；對應調整答案的平移量與逆時針序列。
